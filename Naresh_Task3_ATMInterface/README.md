# ATM Interface

## Internship
Oasis Infobyte – Java Development Internship

## Task
Task 3 – ATM Interface

## Description
A console-based ATM Interface developed using Java and Object-Oriented Programming. The application supports secure login with PIN authentication, deposit, withdrawal, fund transfer, and transaction history using ArrayList.

## Technologies Used
- Java
- OOP
- ArrayList
- Eclipse IDE

## Features
- Login Authentication
- Deposit
- Withdraw
- Transfer
- Transaction History
- Balance Validation
