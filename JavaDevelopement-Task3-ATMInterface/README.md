# ATM Interface

## Internship

Oasis Infobyte – Java Development Internship

## Task

Task 3 – ATM Interface

## Description

A console-based ATM Interface developed using Java and Object-Oriented Programming (OOP). The application simulates basic ATM operations with secure user authentication, account management, transaction processing, and transaction history.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections
- Eclipse IDE

## Features

- User Login with User ID and PIN
- Maximum 3 Login Attempts
- Transaction History
- Cash Withdrawal
- Cash Deposit
- Fund Transfer
- Balance Validation
- Insufficient Balance Handling
- Invalid Amount Validation
- Transfer to Another Account
- Prevent Transfer to Own Account
- Secure Logout / Quit
