# Online Reservation System

## Internship

Oasis Infobyte – Java Development Internship

## Task

Task 1 – Online Reservation System

## Description

A GUI-based Online Train Reservation System developed using Java Swing and JDBC.
The application allows users to login, book train tickets, generate a unique PNR number,
view booking details, and cancel tickets using the PNR number.

## Technologies Used

- Java
- Java Swing
- JDBC
- SQLite
- OOP
- Eclipse IDE

## Features

- User Login Authentication
- Invalid Login Validation
- Train Selection
- Automatic Train Name Population
- Passenger Details Entry
- Class Type Selection
- Journey Date Selection
- Source and Destination Selection
- Ticket Booking
- Unique PNR Generation
- Booking Confirmation
- PNR-based Ticket Fetch
- Ticket Cancellation
- Cancellation Confirmation
- Basic Input Validation
- Database Storage
